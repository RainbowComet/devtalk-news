У популярному веб-сервері Apache HTTP Server було виявлено критичну вразливість, яка може призвести до віддаленого виконання коду (RCE).

Йдеться про CVE-2026-23918 — помилку типу double free у реалізації HTTP/2. Через некоректну обробку пам’яті сервер може бути скомпрометований спеціально сформованим запитом.  

Вразливість зачіпає версію Apache HTTP Server 2.4.66, і у разі експлуатації дозволяє атакуючому потенційно виконувати довільний код на сервері без повного доступу до системи.  

За оцінками дослідників, проблема є особливо небезпечною через масштаб використання Apache — це один із найпоширеніших веб-серверів у світі, який використовується в enterprise-системах, хостингах і критичній інфраструктурі.  

У спільноті кібербезпеки вже попереджають, що подібні вразливості можуть швидко стати мішенню для масових атак, особливо якщо сервери не оновлені. На Reddit користувачі прямо зазначають, що це RCE з високим ризиком (CVSS ~8.8) і рекомендують негайно оновлювати системи.  

Apache вже випустив виправлення у версії 2.4.67, і адміністраторам настійно рекомендують якнайшвидше оновитися.  

⸻

⚠️ Чому це серйозно

* RCE = повний контроль над сервером
* не потребує фізичного доступу
* може використовуватись для:
    * встановлення бекдорів
    * крадіжки даних
    * розгортання malware

⸻

🧠 Висновок

Цей інцидент — ще одне нагадування, що навіть базові компоненти інтернету можуть містити критичні баги.
І якщо сервер не оновлений — він автоматично стає потенційною точкою входу для атак.

Дослідники з кібербезпеки повідомили про нову кампанію проти користувачів macOS, у якій зловмисники використовували Google Ads і бренд Claude Code для поширення malware.

Схема працювала через malvertising: користувачі шукали в Google популярні інструменти для macOS або інструкції, пов’язані з Claude Code, після чого бачили рекламне посилання, яке виглядало як легітимна сторінка. За даними 7AI та Bitdefender, фейкові сторінки імітували документацію Claude Code або інструкції з інсталяції.  

Далі жертві пропонували скопіювати команду в Terminal. У фінальній команді був прихований шкідливий код, який завантажував malware для macOS. У звітах цю кампанію пов’язують із MacSync infostealer — шкідливим ПЗ, здатним красти дані з macOS, браузерів і криптогаманців.  

Окремо дослідники зазначають, що кампанія використовувала техніку ClickFix: користувача переконують, що команда потрібна для “виправлення” проблеми або встановлення інструмента, хоча насправді він сам запускає зараження системи. Подібні атаки небезпечні тим, що виглядають як звичайна технічна інструкція.  

За даними Bitdefender, у кампанії також фіксувалися Windows-пейлоади, але macOS-напрям був окремо націлений на користувачів, які шукають Claude Code та developer tools. Дослідники припускають, що зловмисники могли використовувати скомпрометований рекламний акаунт, щоб оголошення виглядали довірено.  

Головний висновок простий: не можна копіювати команди в Terminal із рекламних сторінок, навіть якщо сайт виглядає офіційно. Для встановлення Claude Code або будь-яких developer tools краще переходити лише з офіційних сайтів або перевірених репозиторіїв, а не з рекламних результатів пошуку.

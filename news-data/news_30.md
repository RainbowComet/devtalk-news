У спільноті користувачів Claude останніми тижнями активно обговорюють можливе погіршення якості відповідей. На Reddit з’являються пости, де користувачі пишуть, що модель стала відповідати більш поверхово, раніше зупиняє міркування й частіше дає стислий результат замість детального розбору.  ￼

Причиною цього частина користувачів називає параметр effort — він справді існує в екосистемі Claude і офіційно використовується для керування глибиною “thinking”. У документації Anthropic сказано, що в Claude 4.6 adaptive thinking калібрується, зокрема, за параметром effort, а в Claude Code доступні рівні low, medium, high і max; для окремих сценаріїв Anthropic прямо рекомендує змінювати effort залежно від складності задачі.  ￼

Втім, ключовий момент у тому, що публічного підтвердження від Anthropic про зниження effort у звичайному чаті немає. Найвірусніший пост на Reddit прямо стверджує, що “це конфігураційна зміна”, але це твердження походить від користувача спільноти, а не з офіційної заяви компанії. Тобто на сьогодні коректніше говорити не про доведений “нерф”, а про масове сприйняття змін у поведінці моделі, яке користувачі намагаються пояснити через effort.  ￼

Окремо підтверджується й інша частина історії: у Claude Code справді є спосіб впливати на effort, тоді як у звичайному Claude Chat такого явного перемикача для користувача немає. Anthropic документує персоналізацію через profile preferences, project instructions і styles, а також дозволяє задавати інструкції на рівні профілю чи проєкту. Саме тому в Reddit набув популярності обхідний шлях: прописати в custom instructions вимогу “reason thoroughly and deeply”, щоб підштовхнути модель до більш розгорнутих відповідей. Це не офіційний “фікс”, але він узгоджується з документацією Anthropic про персоналізацію поведінки моделі через інструкції.  ￼

Таким чином, найточніший висновок зараз такий: користувачі дійсно масово скаржаться на зміну стилю відповідей Claude, параметр effort реально існує й впливає на глибину міркувань, але теза про те, що Anthropic спеціально “знизила effort” у звичайному чаті, поки що не підтверджена офіційно. Зате підтверджено інше: у Claude Code глибину можна налаштовувати, а в чаті — лише непрямо, через інструкції та стиль взаємодії.

Компанія Google Cloud на конференції Google Cloud Next ‘26 представила новий інструмент — Agents CLI, який входить до екосистеми Agent Platform і покликаний стандартизувати процес створення AI-агентів.

Основна проблема, яку вирішує Agents CLI — це фрагментація інструментів. Раніше розробникам доводилося вручну з’єднувати різні сервіси, налаштовувати інфраструктуру та контролювати поведінку агентів. Новий інструмент об’єднує ці процеси в єдиний pipeline.

Однією з ключових особливостей є підхід до зменшення “контекстної перевантаженості”. Замість того, щоб AI-агенти “вгадували”, як працює інфраструктура, Agents CLI надає їм структуровані “skills” і доступ до API. Це робить поведінку агентів більш передбачуваною та знижує витрати токенів.

Інструмент також включає можливості для тестування та оцінки. Розробники можуть запускати локальні симуляції, перевіряти результати роботи агентів і порівнювати різні варіанти перед тим, як виводити систему в продакшен.

Ще один важливий компонент — автоматизація розгортання. Agents CLI генерує інфраструктуру як код (IaC), налаштовує CI/CD-процеси та дозволяє деплоїти агентів у середовища на кшталт Cloud Run або Google Kubernetes Engine.

Окремо Google додала режим Human Mode, який дозволяє розробникам вручну контролювати виконання команд. Це важливо для сценаріїв, де потрібна перевірка або корекція дій агента перед виконанням критичних операцій.

Запуск Agents CLI показує стратегічний напрям Google: перетворити розробку AI-агентів у стандартизований процес, подібний до класичного software development lifecycle. Інтеграція з Vertex AI та іншими сервісами компанії також підсилює екосистему Google Cloud як єдину платформу для створення агентних систем.

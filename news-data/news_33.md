Модель Gemma 4 від Google DeepMind відкриває новий сценарій для розробників: локальний AI-coding без API, підписок і usage-лімітів. У зв’язці з Claude Code її можна використовувати як повноцінного coding-агента, який працює прямо на вашому комп’ютері.

Gemma 4 (зокрема версія близько 26B) використовує архітектуру mixture-of-experts із невеликою кількістю активних параметрів, тому її можна запускати навіть на споживчому “залізі” — особливо з GPU або у квантизованому вигляді.

⸻

Як налаштувати систему

Спочатку потрібно встановити середовище для запуску моделей. Найпростіші варіанти — LM Studio або Ollama. Обидва дозволяють запускати великі мовні моделі локально без хмари.

Далі необхідно завантажити модель Gemma 4. У LM Studio це робиться через вкладку Models, де потрібно знайти Gemma 4 і вибрати квантизовану версію (наприклад Q4 або Q5, якщо у вас обмежена відеопам’ять). В Ollama модель також доступна для завантаження через каталог моделей.

Після цього потрібно увімкнути локальний API. У LM Studio це робиться через Local Server, де потрібно активувати OpenAI-compatible API. В Ollama API працює автоматично після запуску сервісу.

Наступний крок — підключення до Claude Code. У налаштуваннях потрібно вказати локальну адресу сервера (localhost), будь-який API-ключ (він не перевіряється) і назву моделі Gemma. Таким чином Claude Code буде використовувати не хмарну модель, а вашу локальну.

Далі потрібно підключити свій проєкт. Claude Code отримує доступ до папки з кодом і може читати файли, редагувати їх, запускати команди та працювати як повноцінний агент.

* автоматичний дебаг і рефакторинг

Фактично це локальний аналог Copilot або Claude Code без підписки.

Висновок

Зв’язка Gemma 4 + Claude Code показує новий тренд: AI-розробка поступово переходить із хмари на локальні машини.

Якщо раніше розробники були прив’язані до API і платних сервісів, то тепер вони можуть запускати повноцінного AI-агента у себе локально — без обмежень і залежності від провайдерів.

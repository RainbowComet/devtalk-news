Компанія ** Microsoft￼** почала скорочувати використання Claude Code серед внутрішніх інженерних команд і переводити співробітників на GitHub Copilot CLI, повідомляє  The Verge￼.

За даними видання, тисячі розробників Microsoft, які працюють над продуктами компанії, включно з Windows, Microsoft 365 та іншими сервісами, можуть перейти на власну екосистему AI-інструментів замість рішення від Anthropic.

Цікаво, що раніше Microsoft активно експериментувала з різними AI-асистентами для програмування, а Claude Code отримав популярність серед частини інженерів завдяки сильним можливостям у coding-задачах.

Тепер підхід змінюється.

Офіційно Microsoft робить ставку на GitHub Copilot і власний стек AI-інструментів. Неофіційно в індустрії активно обговорюють ще одну причину — вартість використання потужних AI-моделей.

Це добре вписується у тренд останніх місяців:

* компанії рахують не лише зарплати, а й токени
* AI-агенти можуть генерувати великі витрати
* coding-асистенти використовуються настільки активно, що починають впливати на бюджети

Раніше в мережі вже з’являлися скарги користувачів Claude, що навіть дорогі підписки по $100–200 швидко впираються в ліміти або призводять до значних витрат.

Важливо: наразі немає підтвердження, що Microsoft відмовляється від Claude Code саме через фінансові причини. Компанія також може переслідувати стратегічну мету — просування власної екосистеми Copilot.

Але сам факт показовий:

навіть великі технологічні корпорації починають оцінювати AI не лише за якістю, а й за вартістю експлуатації в масштабі тисяч інженерів.

Можливо, найближчі роки боротьба між AI-компаніями буде не лише за найрозумнішу модель.

А за питання:

хто дешевше дає “другого розробника”.
